# 情绪数据清洗与预处理

## 当前实验数据

当前仓库的分类结果来自人工编写的中文模拟文本，仅用于验证流程，不代表真实用户数据。训练集和测试集分别写在 `backend/classification.py` 中，测试集不参与 TF-IDF 拟合。

## 处理规则

1. 删除空文本和无法确定标签的样本。
2. 保留中文表达中的否定词、程度词和上下文，不做过度分词。
3. 使用字符级 1-2 gram TF-IDF，降低中文分词错误带来的影响。
4. 训练集与独立测试集分开维护，避免测试文本泄漏。
5. 个人日记和聊天记录不进入分类训练数据。

## 标签映射

| 标签 | 含义 |
|---|---|
| 积极 | 开心、满足、顺利等正向表达 |
| 平稳 | 没有明显正负情绪或状态平常 |
| 低落 | 难过、孤独、失望、无聊等表达 |
| 焦虑 | 担心、紧张、害怕、压力等表达 |

正式提交前仍需补充公开中文情绪数据集的来源、授权和样本统计。
