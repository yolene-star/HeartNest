# 情绪数据清洗与预处理

## 当前实验数据

更新于2026-11-03：当前保留微型模拟实验，并已补充公开八类语料实验。下述处理规则和四类标签仅描述 `backend/classification.py` 的人工编写文本；测试集不参与 TF-IDF 拟合，仅验证流程，不代表真实用户表现。

## 处理规则

1. 删除空文本和无法确定标签的样本。
2. 保留中文表达中的否定词、程度词和上下文，不做过度分词。
3. 使用字符级 1-2 gram TF-IDF，降低中文分词错误带来的影响。
4. 训练集与独立测试集分开维护，避免测试文本泄漏。
5. 个人日记和聊天记录不进入分类训练数据。

## 标签映射

| 标签 | 含义 |
|---|---|
| 积极 | 开心、满足、顺利等正向表达 |
| 平稳 | 没有明显正负情绪或状态平常 |
| 低落 | 难过、孤独、失望、无聊等表达 |
| 焦虑 | 担心、紧张、害怕、压力等表达 |

## 已补充的公开实验

`backend/public_classification.py` 使用公开混合语料，经 NFKC、空白标准化、去重及冲突文本排除，4159 行保留 4152 行，再按种子 42 分层拆成 3321 训练、831 测试。字符 1–3 gram TF-IDF 仅拟合训练集，比较 LR 与 LinearSVC。保留实际八类标签，不映射为上述四类或产品标签。
