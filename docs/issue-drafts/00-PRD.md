# [PRD] 心栖 HeartNest：情绪陪伴 Agent 与心情日记

状态：需求与核对结果同步至 [GitHub PRD #1](https://github.com/yolene-star/HeartNest/issues/1)，整体产品与新增文案仍待用户最终人工验收。以本轮验收记录为进度依据，历史截图不作为新增功能已通过的证明。

最近更新：2026-11-02。已合并自然风格界面、聊天记忆保存语义、安静陪伴空间及“聊天 → 放松选择 → 湖边 / 小练习”的新增需求。设计目标、已实现行为与待验收项分别说明，本文为总体需求入口。

## 定位与目标

为希望记录感受、被倾听和获得轻量下一步建议的用户，提供自然交流的情绪陪伴 Agent。用户选择具体的小动物伙伴常驻页面，也可以独立写日记、回看心情日历、编辑补充旧记录。产品辅助日常自我回顾，不承担诊断、治疗或效果保证。

核心价值：先陪伴，再由用户决定是否记录、调用旧记忆或寻求下一步。LLM 负责语言理解与表达；本地 Agent 流程管理授权、真实检索、建议选择和反馈，不把模型生成的话当用户经历。

产品主线为“和熟悉的小伙伴聊聊 → 按意愿获得情绪支持 → 需要时一起放松或选择一个轻量行动”。日记、情绪回顾与兴趣画像服务于这条主线，不把首页设计成情绪分析仪表盘，不以记录次数或完成任务衡量陪伴效果。

## 按使用顺序的要求

1. 首次见面：伙伴以自我介绍呈现性格，用户选喜欢的形象；昵称可跳过；询问倾听/一起想办法/随当下调整的习惯。旧日记记忆调用默认关闭，设置可更改。
2. 陪伴主入口：自然聊天，每条消息都有回应。用户可确认、修改或跳过系统情绪初判；已确认标签也可再次修改。角色可动且在桌面常驻、可拖动；移动端使用导航内角色避免挡住操作。角色素材本轮不变更。
3. 记录控制：聊天默认只在当前会话使用，可主动保存原话，或选择连同心栖回应一起保存；原文和回应分开展示。关闭新记录保存后仍可聊天，已有日记仍可查看编辑。
4. 日记入口：独立写作，选择仅保存或先听回应，再确认保存。心情日历与列表互通，点击具体日期后能打开对应日记；支持搜索、编辑、追加和删除。
5. 情绪回顾：展示已确认类别统计与最近七天按日期分布；无记录日期显示未记录，多种情绪可同时存在，不推断平静或计算心理健康分数。
6. 长期记忆：全局开启、单篇允许时，按请求用 TF-IDF 余弦相似度检索已保存记录；展示原文、日期与回应来源。无匹配不编造。关闭单篇授权、关闭全局授权或删除记录后，不得继续引用。
7. 可选下一步：用户请求后提供带来源与适用局限的练习，可尝试、暂不用或换一种。聊天保持自然，不在每句话中堆砌学术术语；证据约束不等于模型每句话经过科学审核。
8. 活动筛选：依据当下诉求、预算、时间与已确认偏好筛选模拟活动，展示费用、时间、地点自选、来源与排序理由。符合预算/时间是硬条件；喜欢/想尝试影响排序，明确反感影响过滤。
9. 反馈与画像：接受、拒绝、调整条件、体验都可记录；默认仅当次选择。用户明确勾选记为长期偏好后，接受→想尝试、体验→已体验、拒绝→该活动类型反感；告知类型范围。画像支持新增、查看、编辑和删除，保留来源与时间。
10. 放松选择：首页提供“想放松一下”，用户可选“去湖边坐坐”“试个小办法”“继续聊聊”或暂时不选。另保留“陪我待会儿”直接进入安静空间，不必先发消息、标记情绪或接受建议。
11. 安静陪伴：进入细节简洁的手绘自然风景，当前宠物留在画面中陪伴。可安静待着，也可展开同一份聊天；不要求计时、打卡、完成任务、写日记或离开后评价效果。

## 陪伴与放松的交互约束

聊天中的情绪初判为辅助信息：默认只显示可展开的紧凑单行标签，不使用大块分析卡片打断陪伴；用户主动展开后再确认、修改或跳过，已确认结果保持轻量展示。

### 自然交流与有依据的建议

- 聊天始终回应；“保存到 Agent 记忆库 / 不保存”控制是否持久化，不是“需要回应 / 仅保存”的聊天模式。独立日记仍可只保存而不请求回应。
- 沟通原则和练习以明确、可核查的研究或专业指南为约束，日常表达保持自然，避免照读问卷、固定安慰模板和每句话附学术术语。当前建议卡提供来源链接、适用范围与局限；不声称每条 LLM 回复都经过科学或人工审核。
- 用户请求建议时提供可选的小办法，依据默认收起，用户可展开。拒绝或换一种不代表用户做错了，也不推断练习必然有效。自然风景用于提供安静空间，不据此宣称心理治疗效果。
- 聊天临时使用、保存新记录、调用历史记忆是不同选择；“不保存”不等于当前消息不会由所配置的云端 LLM 处理。

### 一次轻邀请

- 用户明确表达想休息或放松时，宠物在正常回应之外可以轻轻邀请一次；不因为“疲惫”“低落”等情绪初判就自动推送放松。
- 不在用户明确只想倾诉、不需要建议、否定放松、回顾过去经历、安全回应、已有建议或已进入湖边时追加这类邀请。
- 用户点“看看放松方式”才打开选择框，不自动跳转场景；点“先不用”则保留聊天，本次当前对话不再主动邀请。手动入口始终可用。
- 拒绝邀请不新增日记、不写入兴趣画像，也不改变长期偏好。选择小练习后的反馈继续遵循单次反馈与长期偏好授权的区分。
- 当前采用保守的明确请求匹配，未单独接入 LLM 邀请意图分类；漏触发时仍可手动进入。一次邀请状态属于当前打开页面内的会话，切换产品页面会保留，刷新或关闭网页后重置，不承诺跨会话保存拒绝状态。

### 安静空间的操作与隐私

- 第一版为“湖边发呆”：沿用用户确认的纯风景背景和已选宠物，不重新设计角色；只呈现一个场景伙伴，隐藏重复的侧栏、浮动桌宠和主导航。
- 默认静音。环境声音须主动开启，可调音量；关闭、离开场景或页面进入后台时停止。当前为 Web Audio 本地合成环境声，不是湖水实地录音，不请求麦克风权限。
- 背景保持静态，可有轻微涟漪与宠物动画。支持“减少动态”及系统减少动态偏好；轻触宠物仅短暂回应，不自动发消息或保存记录。
- “想聊聊”展开原聊天面板，草稿、历史和记忆保存选择继续沿用；收起或返回陪伴不丢失内容，进入场景本身不新增日记。
- 桌面聊天与宠物合理分布；手机聊天展开时可暂时隐藏场景宠物，收起后恢复，避免挡住输入与发送。手机主页面沿用导航内伙伴入口。
- 放松选择框支持 Escape、键盘焦点约束与关闭后焦点恢复；“继续聊聊”回到原输入框。场景中 Escape 按“关闭选择层 → 收起聊天 → 返回陪伴”的当前层级处理。
- “换个地方”只列出实际可用场景。森林、窗边等尚未交付，不提供可进入的虚假选项。

## 界面与信息结构

桌面和平板的手账框架固定在视口内：右侧纸页独立滚动，左侧格纹封内、目录与装订环不跟随移动；切换栏目返回纸页顶部。日记列表与详情保留各自滚动，手机仍为整页滚动。实现与回环记录见 `docs/design/notebook-fixed-frame/README.md`。

日记工作区：新建日记使用单独写作页面，不嵌入所有记录列表。返回列表与再进入写作在当前会话保留未保存草稿，旧记录编辑和补充不改动该草稿；保存后定位到新记录。桌面记录列表与详情等高、分别滚动，不因左侧记录多而撑长右侧；窄屏为列表→详情→返回列表的单层浏览。验证记录见 `docs/design/diary-workspace/README.md`。

动画数量约束：普通页面只有悬浮桌宠动态；欢迎区与各类头像/伙伴预览使用静态形象，聊天空白区不再放重复宠物。湖边仍为独立单宠物场景，保留减少动态设置；手机沿用静态导航伙伴，不额外显示悬浮宠物。

2026-11-02 新增界面要求：整体呈现为一本绿色活页手账，参考用户提供图中的封内目录、装订环、纸页和少量胶带细节，保留既有绿色/奶白主色与深绿色文字。桌面为左侧封内目录与右侧纸页，手机为单页加底部导航；四项功能结构与轻量情绪初判不变。湖边仍为独立沉浸场景。首版已在本地实现并完成技术回环，设计细节与证据见 `docs/design/notebook-ui.md`，视觉最终认可待用户反馈。

沿用用户认可的自然风格：灰绿底色、白色圆角卡片、柔和绿色操作、简洁文字和手绘自然场景。桌面侧栏与手机底栏均为“陪伴 / 日记 / 回顾 / 我的”；日历归入日记，隐私与兴趣画像归入我的。保留已有独立宠物形象及动画，不以简单几何拼接或参考图中的角色替换。

安静空间为可退出的独立沉浸视图，不扩展成必须参与的冥想课程或任务系统。新建日记与编辑旧日记保持独立草稿；未记录日期不推断心情，绿色不表示情绪优劣。

## 功能、数据与接口

前端 React/Vite；后端 FastAPI；SQLite 状态持久化；Docker Compose 封装；可选 DeepSeek 兼容 API；本地规则在模型失败时回退并说明来源。

| 对象 | 主要字段 |
|---|---|
| 记录 | id、kind、text、recorded_at、emotion、emotion_status、allow_retrieval、response_text、response_created_at、addenda、updated_at |
| 画像 | id、content、type、status、confirmed、source_id 或 source_feedback_id、created_at、updated_at |
| 活动 | id、name、type、time、cost、description、source；返回时含 reasons，地点由用户自选 |
| 反馈 | id、recommendation_id、action、experience、remember_preference、created_at；确认画像时含 profile_id |

接口：`/api/companion/respond`、`/api/diaries` 与单篇编辑/删除/情绪/补充、`/api/calendar`、`/api/analyze/emotion`、`/api/memories/search`、`/api/profile` CRUD、`/api/recommendations`、`/api/feedback`、`/api/settings`、`/api/metrics/emotions`。

## 验收标准

- 首次选择伙伴后可进入陪伴，输入内容后角色和按钮正常，关键操作在手机不被角色或底部导航遮挡。
- 保存、临时聊天与整段保存的行为符合所选模式；失败保留原文并可重试，不重复生成记录。
- 情绪修正后日记、日历和回顾使用修正结果，跳过标签不进入已确认统计。
- 记忆引用有真实来源与日期；撤回单篇或全局授权、删除记录均立即生效。
- 画像编辑与明确确认的反馈影响后续活动筛选；单次拒绝不擅自推断长期反感。
- 日记编辑与补充刷新后保留；七天图能定位具体记录，未记录不推断情绪。
- 分类实验输出准确率、宏平均 F1、混淆矩阵与至少三个错例；明确区分公开混合语料基线、微型模拟实验与在线 LLM 验收。
- Docker 下可从头启动，实际页面完成记录→回应→保存→回看→建议→反馈→偏好更新→隐私撤回；留存可重跑脚本和截图。
- 不发消息也可打开“想放松一下”；选择湖边进入真实场景，选择继续聊天回到输入框，取消与 Escape 均可退出并恢复合理焦点。
- “今天很累”不会仅凭疲惫状态触发邀请；明确提出想放松时可邀请一次；拒绝后同一当前对话不再邀请，手动入口仍可用。
- 倾诉限定、历史提问和安全回应不触发放松邀请；一次邀请拒绝不改变日记、画像或长期偏好。
- 小练习来自实际建议接口，可展开真实来源、替换练习；请求失败后可重试，不展示虚构的成功结果。
- 湖边默认静音，开关声音和音量可用，离开或进入后台停音；减少动态切换静态帧，并尊重系统偏好。
- 从聊天进入湖边、展开聊天、收起、返回后，草稿与消息保持；不因进入、轻触宠物或退出场景自动保存记录。
- 在 390、785、1440 像素宽度检查风景、宠物、选择框和聊天控制，按钮可点击、发送不被遮挡；实际页面截图须人工查看。

## 边界与后续项

当前是单用户、本地课程原型。活动目录是模拟数据，不承诺实时地点/营业状态；没有多用户认证、公开公网运行隔离或跨设备同步。在线 Demo 是可选项，不能直接把当前单用户库暴露为多人共享服务。

聚类、实时地图、联网探店、复杂多智能体、多模型对照保留扩展，不阻塞核心原型验收。公开分类数据实际标签不含产品的焦虑/疲惫等全部类别，结果不作为全标签覆盖证明。新来源改编的建议文案需人工验收后再正式发布。

森林、窗边等新增安静场景尚未实现；进一步精简首次使用步骤、放松邀请的 LLM 语义识别与跨会话延续可后续完善，不列为本版已交付能力。当前不加入强制放松计时、每日任务、连续打卡或心理健康评分。

### 对话驱动的个人资料确认与灵活画像

聊天识别用户明确的称呼、回应方式变更，以及自述的小习惯和个人特征。Agent 在对应回应下展示确认卡片：说明拟保存内容，支持查看来源原话、确认更新或暂不记录。确认前不修改设置或画像；取消不写入，失败可以重试。固定设置直接更新「我的」对应字段，确认后当前页面称呼同步刷新。单项资料的确认独立于聊天全文保存，不自动新增日记，也不自动打开记忆调用。

「我的」新增「关于我的一些小事」，按小习惯/个人特征展示文本、原话来源、确认与更新时间，支持手动补充、编辑、删除。兴趣偏好继续独立展示。新提议与已有画像跨类别做本地规范化及相似度去重；固定称呼不再重复记录成特征。去重属启发式，不能保证识别全部语义重复，用户可自行编辑删除。

复用现有结构化 LLM 理解请求提取候选，候选类型与长度受限，来源必须逐字存在于当前消息。没有模型时仅识别明确改称呼及部分明确习惯，不能保证理解所有自然表达。拒绝记录、否定/假设、第三方转述及短期情绪不作为本地画像候选。待确认候选仅在进程内保留30分钟，最多128项，过期或服务重启需重新提议。已手动更新的固定设置不能被旧卡片覆盖。

测试与截图见 `docs/design/profile-proposals/README.md`。真实外部模型语义测试本轮被自动审批阻止，未将该段测试文字发送给外部服务，不将模拟模型验收等同真实 DeepSeek 验证。

#### 首页主动开场（2026-11-03）

聊天输入区采用紧凑两行布局，活动入口与折叠设置、发送按钮同在底部工具栏；桌面及手机实测高度 98px，多行内容在输入框内滚动，工具按钮保持可点击范围。设置浮层展开不推高输入区。验证见 [紧凑输入区](../design/compact-composer/README.md)。

陪伴首页由当前宠物先在聊天区说一句简短的开场白，用户无需先发送消息。开启记忆时，仅参考最近 7 个北京时间自然日内、允许检索且已确认的心情；优先使用最新记录日的最多 3 条心情，旧日低落不覆盖较新的开心。同日有多种感受时保持开放，不强行归为单一状态。措辞指向“最近记录过”，不把历史情绪判为当前情绪，不自动引用日记细节，也不主动安排练习。

关闭记忆、没有合适记录、仅有待确认/跳过的标签、记录过期或开场接口不可用时，使用带称呼的通用问候。首版按已确认标签生成受控文案，不额外向云端发送历史日记，也不声称已全面理解日记语义。开场不写入日记或画像，并作为首轮回应的上下文帮助理解用户接话。

同一会话保留一个开场；切页不会重复追加，用户开始发送后不再改写。刷新网页视为新会话，重新按最新授权与状态生成。验证与截图见 [主动开场验证](../design/companion-opening/README.md)。

陪伴页的当前会话在产品内切换「日记」「回顾」「我的」、打开历史日记或切换放松/湖边入口时保持，不重建聊天状态。保留原话、回应、未发送草稿、当前保存选择、情绪标记、资料确认状态、建议与失败重试状态。请求进行中切换页面，返回后仍可看到原请求结果。仅隐藏非活动的陪伴页并关闭其临时抽屉、弹窗与湖边场景，避免遮挡其他页面或后台播放环境声音。

只在请求 Agent 回答时保留相应的用户对话：活动讨论入口发送对应提示词，小建议/练习/更换建议均先追加一条可读用户请求，再追加 Agent 回应。请求失败保留原用户消息并提供重试，重试不重复追加用户消息。更换建议在后续回应中展示新卡片，旧建议标题、步骤与来源保留。打开工具、切换场景、取消、情绪标记、资料确认、保存设置以及接受/拒绝建议等普通操作不追加「你选择了…」提示，结果只显示在对应控件或卡片内，避免刷屏。

会话保留范围是当前打开页面内的交互和页面切换；本轮不新增浏览器持久化聊天存储，刷新/关闭网页会结束临时会话。入口生成的小建议/更换建议请求不自动保存为日记或长期 Agent 记忆，手动聊天仍遵循原有保存授权。验证脚本与截图见 `docs/design/conversation-continuity/README.md` 和 `docs/design/floating-tools/README.md`。

### 放松建议的依据与偏好审查（2026-11-03 实现与回环）

每条行动建议须来自核对过的文献方法、用户当次明确表达或获授权且已确认的偏好，或两者共同支持。偏好不能覆盖行为风险、当前条件和用户拒绝；饮酒消愁、赌博、失控或已产生明显负面影响的行为不因用户喜欢而进入正向推荐。游戏、咖啡、购物等结合具体背景判断，不把活动名称直接等同“不良嗜好”，也不给用户作成瘾诊断。模型自然表达，后端校验受控建议与来源，不能只依赖 prompt。

卡片默认收起“依据与适用范围”，展开显示文献支持、个人偏好或两者共同支持，以及改编、来源链接和限制。目前接入 WHO 压力自助指南的四类动作、音乐方向与明确的绘画/阅读偏好；活动接口按受控映射筛选模拟活动。关闭记忆时不使用历史画像；当前明确表达可用于本次讨论。饮酒、吸烟、赌博及擅自加药不作为放松候选。

“先不用”“换个更轻松的”“做了不舒服”默认在当前会话排除该办法，不自动成为长期反感；不适时先停止，不自动追加新练习。勾选“也确认以后避开这个办法”并拒绝或报告不适后，才写入已确认的反感画像，可在「我的」编辑或删除，后续使用仍遵循记忆开关。刷新页面会结束本次会话的临时排除。

具体动作与引用由后端受控库返回，不让模型生成引用。日常聊天仍使用既有生成式 LLM，并受沟通提示约束；当前意图、否定及主体识别采用保守启发式，不能保证覆盖全部自然语言，也不声称每句话已被科学或专家审核。真实自然步行研究不能外推为网页湖景疗效。详细资料与限制见 [放松建议文献与偏好规则](../research/relaxation-evidence-and-preferences.md)，实际测试与截图见 [验证记录](../design/advice-evidence/README.md)。
