## 可复现处理

原 CSV SHA-256：`f8a96c78f11b070937166968703ae89e9065b5d7508328b0c94f174626e8f484`。

1. 读取 `text`、`emotion` 两列；文本 NFKC、连续空白标准化及首尾清理，保留否定与程度词。
2. 去除空文本/标签和同文本同标签重复行；同一标准化文本有冲突标签时整个文本排除。
3. 4159 原始行 → 4152 清洗行；空行 0、重复行 5、冲突文本 1（两种标签记录均排除）。
4. 种子 42，清洗后按八类分层切分：训练 3321、测试 831；无完全相同的标准化文本跨集合。
5. 字符 1–3 gram TF-IDF，`min_df=2`、最多 40000 特征，仅拟合训练集；比较 LogisticRegression 与 LinearSVC，标签保持原值。

运行 `python backend/public_classification.py`。指标、八类分布、混淆矩阵及各 20 个错例见[实验记录](../public-classification/README.md)和[原始结果](../public-classification/metrics.json)。固定拆分 LR 宏 F1 0.8574，SVM 宏 F1 0.8719。

## 八类语料与产品标签的关系

**当前没有将八类公开模型部署到线上，也没有自动执行下面的语义对应。** 本表用于说明边界，不用于计算产品准确率。

| CSV 实际标签 | 产品语义参照 | 不可直接转换的原因 |
|---|---|---|
| 開心語調 | 开心；旧别名积极 | 对话语调未必等于日记整体感受 |
| 平淡語氣 | 平静；旧别名平稳 | 平淡语气不能证明内心平静 |
| 悲傷語調 | 低落 | 需结合主体、否定及时间变化 |
| 憤怒語調 | 生气 | 别人的愤怒不代表用户生气 |
| 厭惡語調 | 无直接对应 | 不强行归为生气或低落 |
| 疑問語調 | 无直接对应 | 疑问不是焦虑 |
| 關切語調 | 无直接对应 | 关切不是恐惧或焦虑 |
| 驚奇語調 | 无直接对应 | 惊讶可积极、消极或混合 |

产品还有疲惫、焦虑、混合/说不清、其他，CSV 没有直接对齐类别。上游文字说明含“恐懼”和重复“悲傷”等不一致内容，以实际 CSV 为准；保留原卡，不掩盖差异。

## 三种结果分开报告

- 微型模拟实验：验证流程，结果在 `data/classification_metrics.json`。
- 公开实验：固定拆分上的准确率、宏 F1 和错例；未按电影、作者或模板分组，近似文本可能跨集合，不能外推真实日记表现。
- 线上分析：可选 LLM，失败退回关键词规则，最终由用户确认。`confidence` 未校准；真实模型小样本一致性不等于通用准确率或情绪改善。

现有分类脚本不读取个人日记、聊天、画像或反馈，未实现自动回流训练。
