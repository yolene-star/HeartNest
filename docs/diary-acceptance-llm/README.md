# DeepSeek 文本理解与陪伴验收

日期：2026-11-02。状态：**LLM 接入与流程验证通过；用户已确认 008 应为平稳，按复核后的参考标签，已保存的 8 篇模型初判全部一致。**

## 已验证的实现

- 情绪初判与聊天意图使用经过严格字段校验的 LLM 输出，关注否定、转折、主导感受及日记叙事。
- 用户标签优先；自动初判不直接成为已确认情绪。
- LLM 判断意图后，后端仍检查记忆权限并执行实际检索，模型不能绕过开关或编造引用。
- 未配置、网络错误、连接重置和无效 JSON 可回退本地规则，来源字段区分模型与规则。
- DeepSeek 官方 API 的理解和自然回复请求均关闭思考模式，避免短输出预算被思考过程耗尽。

## 环境与方法

真实 DeepSeek `deepseek-flash`、FastAPI、Python 3.11 Docker 镜像、Nginx 前端和 Edge 无头浏览器。使用独立 Compose 项目 `heartnest-llm-acceptance-final-1102`、18080 端口、专用测试卷。默认实例数据未参与这组日记测试。

8 篇均为已审核的虚构文本，不包含真实用户个人经历。最终逐篇结果见 `results.json`。首次未关闭思考模式的结果保留为 `initial-results.json`；期间一次网络创建失败的运行不属于最终结果。

## 回复人工检查

已逐篇阅读 `results.json` 中的自然回复：均回应当前日记细节，未输出历史检索提示，也未使用虚构日记引用。007 的回复承接了完成任务、停下来感受满足和买水果的细节；浏览器中的快乐分享也得到自然回应和一个继续聊天的问题。
