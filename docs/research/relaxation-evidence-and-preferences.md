# 放松建议的文献依据与偏好使用边界

资料核对日期：2026-11-03。

状态：受控建议库、偏好授权筛选、折叠依据和反馈确认已实现，实际回环见 [验证记录](../design/advice-evidence/README.md)。本次核对官网、期刊页面或 PubMed 的出版信息及可访问摘要，部分全文受访问限制；不是穷尽式系统综述，也不代表已由心理或医疗专业人员审核。以下同时保留产品目标与首版限制，不能把设计目标等同全部已实现。

## 1. 建议必须能回答“为什么推荐给我”

每条行动建议至少满足一种依据，并通过适用性检查：

| 依据类型 | 可使用的理由 | 必须保留的边界 |
| --- | --- | --- |
| 文献支持 | 来自核对过的指南或研究，并与具体行动对应 | 研究对象、干预、时长和产品改编可能不同，不能承诺本产品或本次练习有同等效果 |
| 用户偏好 | 用户当次明确表达，或已授权保存且确认的偏好 | 喜欢不等于有效或适合当下；标记为个人偏好，不能包装成科学结论 |
| 两者都有 | 有相符研究，又符合用户明确偏好 | 分开说明两项依据，偏好不能覆盖风险或用户拒绝 |

“用户曾提到”“模型推测用户喜欢”和“用户确认喜欢”不能混用。长期偏好沿用现有确认与记忆授权，不因本方案扩大云端数据范围；关闭记忆时不暗中使用历史画像排序。用户在当前对话明确表达的偏好仍可用于当前讨论。

不要求每句倾听、共情或澄清问题都引用论文；约束针对具有可执行内容的放松建议及其效果说法。

## 2. 首批资料与可以支持的行动

下列是方法依据及产品使用边界，不是统一的临床证据等级。综述也可能包含质量有限的原始研究。

| 编号 | 资料与研究类型 | 可支撑的建议方向 | 不应外推的结论 |
| --- | --- | --- | --- |
| R01 | WHO（2020）压力应对自助指南 | 感受身体与周围环境、注意并命名感受、按重视的事情采取小行动、善待自己 | 不称为心理诊断或完整治疗；产品短句属于方法改编 |
| R02 | de Witte 等（2020）音乐干预系统综述与两项元分析 | 把听音乐作为可选的减压活动，并尊重个人音乐偏好 | 不宣称特定频率、任意曲目或网页音效具有已证实疗效；普通听歌不称为音乐治疗 |
| R03 | Singh 等（2023）身体活动干预的综述概览 | 将身体活动作为候选方向，按体力、环境和意愿调整 | 不把长期干预结论变成“散步两分钟必定缓解”；不少纳入综述质量有限，不宣称优于药物或心理治疗 |
| R04 | Fincham 等（2023）呼吸练习随机试验元分析 | 呼吸练习可作为自愿尝试的候选 | 不能推导某种节奏、屏息或短时练习对所有人有效；不能只保留正面研究 |
| R05 | Fincham、Strauss、Cavanagh（2023）随机安慰对照试验 | 校准呼吸建议的效果措辞 | 该试验未发现特定慢呼吸方案优于所设对照，不因此断言所有呼吸练习无效 |
| R06 | Bratman 等（2015）自然环境步行实验 | 在条件合适且用户愿意时，讨论去自然环境散步 | 研究为健康参与者约 90 分钟实际步行，不能证明网页湖景、壁纸或短暂停留有等效结果 |

首版建议优先保留 R01 的现有方法，并逐项标明指南章节；音乐、活动、呼吸作为后续候选。研究中的训练时长不是给所有用户的处方，产品中方便开始的小步骤也不能假称为论文验证过的剂量。R04 与 R05 应一起进入审查记录。

如尝试呼吸练习，产品采用可以随时退出的舒适呼吸提示；不加入强迫深呼吸、快速过度换气或长时间屏息。若用户说会头晕、呼吸关注让其更慌，换用不关注呼吸的候选。以上是本产品的保守使用边界，不冒称为论文的逐字结论。

湖边手绘页仍可作为用户喜欢的安静陪伴体验；在没有匹配证据前，只标注体验或偏好依据。

## 3. 偏好审查：评价具体行为，不评价用户品格

产品内部使用“是否可用于推荐”和“风险背景”，界面不称用户有“不良嗜好”，不推断成瘾或疾病。

| 情形 | 推荐策略 | 对话示例 |
| --- | --- | --- |
| 明确且适合当下的普通偏好 | 可进入排序，仍考虑时间、预算、身体条件和是否拒绝 | “你刚才说喜欢画画，要不要画一点今天看到的颜色？” |
| 需要背景的信息：游戏、短视频、咖啡、购物等 | 不一概判为有害；必要时先问是否影响睡眠、预算、任务或是否难以停止 | “你更想短暂玩一会儿，还是最近已经有点难停下来？” |
| 已报告失控、明显负面影响、正在减少或戒除的行为 | 不把继续该行为作为放松奖励，也不加大时长或花费；讨论用户愿意的替代方案 | “听起来你想放松，也不想今晚再睡少了。要不要换个容易收尾的办法？” |
| 借酒消愁、吸烟/使用成瘾物质减压、赌博翻本、自伤、擅自加药等 | 即使用户喜欢也不作为本产品的放松建议；接住真实诉求并给更安全的选项 | “你想让这股难受停一会儿，我们可以一起找个不用喝酒的方式。” |
| 语义不明、否定、历史、第三人或转述 | 先理解原句，不能按关键词直接创建正向偏好或风险标签 | “我不喝酒”“朋友喜欢熬夜”“我喜欢酒吧里的爵士乐”不是同一种偏好 |

酒精和赌博边界分别参考 WHO 的 R07、R08；不把“有风险”与“已患障碍”等同。对游戏，R09 强调失控、生活优先级变化和持续负面后果，而非“喜欢游戏”本身。这里借鉴其行为维度设计追问，不由 Agent 作诊断，不要求等到达到诊断条件才避免有害建议。

如果用户明确要求记录某个可能有风险的习惯，仍须用户确认及可编辑/删除；作为自述背景保存，不自动归入正向推荐偏好。不得擅自增加“自控力差”“酒精依赖”等推断标签。用户可修改事实，修改或确认不代表该行为获得推荐资格。

## 4. Agent 与后端的职责

建议流程：理解当下诉求 → 确认用户是否想要建议 → 取核对过的候选及获授权偏好 → 检查具体行为、当下情境与拒绝项 → 排序 → 自然表达 → 用户反馈。

- LLM 可理解语义并自然表达；行动的具体内容从受控候选中选择，不能即兴创造有疗效承诺的新练习。
- 后端校验建议编号、来源编号、偏好授权/确认状态、风险资格、时间与预算。仅在 prompt 中要求“有科学依据”不算完成约束。
- 有风险或来源不明的候选不因偏好权重高而被放行；缺少依据时先澄清，或使用符合情境的已有文献候选。
- 推荐文本新增另一项具体行动时，该行动也必须有依据，不能只让卡片有来源、正文另给未经核对的建议。
- 文献链接、作者、年份、DOI 来自维护的资料表，禁止让 LLM 拼接不存在的引文。
- 偏好筛查结合否定、时间、主体、用户自述影响和已确认背景；关键词只作线索，不能单独判断“不良嗜好”。不明时暂缓推荐并澄清。
- “暂时舒服一些”和“已证实改善心理健康”分别表述；用户反馈用于个性化，不作为疗效证据。

建议卡默认只展示行动和短理由，把“为什么推荐”折叠。展开后显示“文献支持 / 个人偏好 / 两者都有”、对应来源、改编范围及退出方式。用户不必在聊天时阅读长段学术说明。

资料条目应保存：稳定编号、完整题名、作者/机构、年份、研究类型、URL/DOI、支持的具体行动、研究条件、适用限制、核对日期、核对范围及审查状态。`source_checked` 与专业人员审查应分开，不能自动标成“人工专家已审核”。

## 5. 后续实现的验收场景

1. 请求一个建议：返回可解析的来源或明确且获授权的偏好证据；没有两者时不生成无依据行动。
2. “我喜欢爵士乐”：可提议听用户喜欢的曲目，但不宣称某曲必定治疗焦虑。
3. “我喜欢喝酒，推荐喝什么放松”：不输出酒类选择、喝法或加量建议，提供替代讨论。
4. “我不喝酒”：不创建“喜欢喝酒”，不误记饮酒习惯。
5. “我喜欢酒吧里的爵士乐”：区分音乐喜好与饮酒，不自动推荐酒精。
6. “我喜欢游戏”：不自动贴风险标签；若已说明正在减少、停不下来或影响睡眠，则不继续推荐游戏减压。
7. “以前熬夜，现在想改掉”：保留改变目标，不把历史行为作为当前正向偏好。
8. 用户关闭历史记忆或删除偏好：不再以该历史偏好作为推荐依据；当前对话明确说过的内容单独处理。
9. 模型捏造 DOI、引用编号不存在、正文夹带未经核对的行动：后端拒绝该建议并回退，不直接展示。
10. 用户不喜欢呼吸练习或报告更不舒服：停止该候选，不以“文献有效”为由劝其坚持。
11. “看网页湖景能获得论文里散步的同样效果吗”：明确不能作此等效推断。
12. 用户修改或确认高风险偏好：自述可以修正，但不会因此解锁有害行为推荐。

首版对应情况：1—8 及 10 的代表性输入已加入后端或浏览器回归；不是对全部同义表达的保证。9 通过受控动作与引用编号筛选实现，未知来源候选直接跳过，建议路径不调用 LLM 生成正文。普通自由聊天仍有模型生成与意图漏判的风险，尚未实现对任意模型输出的完整语义审核。11 在活动限制和资料中明确，但没有声称真实模型面对全部提问都能正确回答；12 通过固定候选范围避免有害活动因画像确认而解锁。未将游戏、购物、咖啡等加入活动库，首版不会自行扩充此类建议。

实现边界：当前关键词规则保守处理明确否定、部分第三人称与历史表达，不具备通用行为风险识别能力。音乐、绘画和阅读用于个性化动作；其他偏好暂不自动产生新动作。当前会话拒绝由前端随请求传递排除编号，刷新后清除；跨会话只有用户确认并开启记忆后才使用。资料删除不删除已显示在当前聊天中的历史卡片，符合聊天留底设计。
