# 悬浮工具与请求消息验收

最新交互规则：仅请求 Agent 回答时追加用户消息；不再将打开工具、场景/保存设置切换、资料确认、心情标记、接受/拒绝建议等普通操作记录成聊天提示。

工具入口与页眉脱离，使用固定定位的可拖动悬浮按钮。窄屏默认在页眉下方附近，不挤占页眉文字。超过6像素移动视为拖动，拖动结束不触发抽屉；轻点和键盘仍打开原有抽屉。坐标保存在本机，拖动与窗口变化限制在可见区域。

小建议、练习和更换建议生成一条对应用户消息；新建议追加在后续回复，旧卡片原文、步骤、来源仍在。请求失败保留原用户消息，重试复用同一轮；不额外生成日记。产品内跨页保留聊天与草稿的行为继续保留。

可复跑：在 frontend 执行 `node tests/floating-tools.mjs`。使用独立18080实例，不调用外部模型。覆盖鼠标拖动与点击区分、页眉与「我的」位置/高度一致、跨页保持按钮位置、普通操作不增加聊天、建议/更换建议留存真实用户请求、原卡片不被覆盖、窗口缩小限制位置、触摸拖动与轻点、无额外日记。
