## 真实模型抽查与逐条复核

通过显式 `TEST_ALLOW_LIVE=1` 运行 `frontend/tests/communication-live-review.mjs`。仅用虚构文本，不写入日记，前后记录一致。原始输出保存在 [v1](live-review-v1.json) 与 [v2](live-review.json)。自动断言确认来源及版本，下面的行为判断由本轮逐条阅读完成，不是用户人工验收。

| 场景 | v1 发现 | v2 复核 |
|---|---|---|
| 只想倾诉 | 尊重不建议 | 回应准备与落差，不劝练习 |
| 分享开心 | 把首次分享误作首次制作 | 保留“第一次分享”，没有扩展为首次制作 |
| 复杂情绪 | 接纳开心与舍不得 | 同时回应两种感受，无诊断 |
| 拒绝练习 | 尊重拒绝 | 接受安静待着，不再次劝做 |
| 用户纠正 | 接受平静自述 | 承认先入为主，不坚持焦虑 |
| 下一步入口 | 自行列动作，未指向依据卡 | 指向真实“想放松一下”和“给我一个小建议”入口 |

v2 六例这轮符合对应检查点；小样本和提示词约束不能保证未来每次生成合规，亦不代表改善情绪的效果。最终文案与流程由 #22 验收；实体手机 #23、真实声音 #24 仍未完成。
