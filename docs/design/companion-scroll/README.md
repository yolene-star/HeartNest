# 陪伴页双栏独立滚动

2026-11-03。桌面宽度大于 1100px 时，聊天与右侧建议栏共享有限的视口高度，各自滚动。聊天标题和输入框保留，消息区滚动；右侧活动、日记入口和近期记录在建议栏内滚动。两侧设置 overscroll containment，滚动到边缘不传递给外层纸页。外层仍可在欢迎区域和双栏之间滚动。窄屏上下排列保持原有自然页面布局。

问题复现：修改前执行 `node tests/companion-scroll.mjs`，实际滚轮不能改变右侧 scrollTop，失败于独立滚动断言。根因是建议栏未设置有限高度及 overflow，长内容撑高了外层纸页。

验证：Vite 与 Docker 构建成功，已部署默认 8080 前端。修改后上述测试通过：1363×871 和 1363×650 双栏真实滚轮、左右互不影响、底部不发生滚动传递、输入框可见；781/390 无横向溢出且保持上下布局。`node tests/notebook-fixed-frame.mjs` 回归通过。

聊天使用仅注入浏览器 DOM 的虚构长文本，活动接口用浏览器 mock，无保存操作。默认日记与画像前后快照一致。两张截图已打开检查，包含本地既有近期记录，仅供本地审核，公开前需脱敏。此验证不替代用户验收。
