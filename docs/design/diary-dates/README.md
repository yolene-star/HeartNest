# 日记不允许未来日期

2026-11-03。统一按北京时间（UTC+08:00）判断今天。日历中未来日期不可选；浏览未来月份时提示等待日期到来，详情区不出现新建入口。普通新建日记仍默认今天，编辑正文不改变日期；当前没有新增日期选择器。

后端新增及修改 recorded_at 都校验有效 ISO 日期/时间，拒绝北京时间未来日期，返回 422。带时区的时间先换算到北京时间，再判断自然日；同一天的较晚时间仍允许。无时区的日期按北京时间解释，保存为 +08:00 时间。拒绝修改时不会部分更新正文。默认创建、补充和更新时间也使用北京时间，最近心情统计采用相同日期边界。

已有记录不作自动重写或删除。接口可补记今天或过去；前端本轮只限制未来日历选择，没有额外增加补记日期表单。
