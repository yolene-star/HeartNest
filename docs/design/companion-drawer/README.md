# 窄屏书签与陪伴工具抽屉

2026-11-03：陪伴页在宽度不超过 1100px 时，于纸页左上角展示书签形「工具」入口。点击从右侧打开奶油色与鼠尾草绿的抽屉，避免辅助功能排列在聊天下方。宽屏沿用侧栏。

抽屉包含活动讨论、放松选择、湖边陪伴、日记入口、近期记录、记忆调用状态。活动仍发送普通聊天开场消息，不恢复旧的独立筛选表单。近期记录可打开对应条目；没有记录时展示空态。与桌面共用日记/近期记录组件。

使用原生 modal dialog 避免背景控件被点击，支持关闭按钮、遮罩、Esc、Tab/Shift+Tab 焦点循环与关闭后回到书签。抽屉内容独立滚动，标题和关闭按钮固定。关闭保留聊天草稿和会话，切到宽屏自动收起。
