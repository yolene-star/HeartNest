# 日记独立写作与分栏浏览

2026-11-02，按用户两条浏览器意见调整：

- “＋ 写日记”和日历空日期的写作入口进入独立写作页面，列表、详情、日历切换标签不与新建表单同时出现。写作页可返回列表；在这两种视图间切换保留当前未保存草稿，与旧日记编辑文本分开。保存后定位到新记录详情。此草稿仅限当前日记组件会话，不承诺刷新后恢复。
- 桌面宽度大于 1100px 时列表与详情等高、独立纵向滚动，列表搜索栏固定在列表上方；两栏通过 overscroll-behavior 阻止滚轮在边界继续带动整页。长列表不再撑出右侧大片空白。
- 手机与窄屏只显示列表或详情其中一层，详情可返回所有记录；打开记录时重置详情滚动位置并转移焦点。
