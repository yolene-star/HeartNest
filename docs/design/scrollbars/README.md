# 按需显示滚动条

所有页面、嵌套滚动容器、横向区域、抽屉和原生输入框的滚动条默认透明。实际滚动时显示绿色细条，最后一次滚动结束约 900ms 后隐藏。保留原生滚动和固定滚动条占位，出现或隐藏不改变页面宽度。

实现：全局捕获非冒泡 scroll 事件，每个容器使用独立定时器，卸载时清理。没有通过 overflow:hidden 禁止滚动。

验证：前端构建、Docker 部署、`node tests/scrollbars.mjs` 通过。测试在隔离 18081 环境运行，覆盖空闲/滚动/空闲、尺寸不变、横向/嵌套/textarea 滚动和手机工具抽屉。浏览器显式关闭 headless 的 hide-scrollbars 默认参数，避免截图隐藏真实滚动条。截图已打开检查。

localhost:8080 更新同一已验证前端镜像，仅重启前端，保留后端与个人数据。
