# 固定纸页布局

2026-11-03。此设计取代此前「右侧整张纸页滚动」的布局。

## 布局规则

- 所有普通页面共用三行结构：固定页眉、有限高度的内容区、固定页脚。外层纸页与窗口不滚动，页码始终可见。日记、回顾、我的仅中间内容滚动。
- 陪伴页中间也不整体滚动：欢迎卡压缩到 118px（短窗口 82px），聊天和右栏分配剩余高度。消息与右栏各自滚动，标题与输入框保留。
- 窄于等于 1100px 时优先保留聊天空间，不展示侧栏的重复日记入口；所有日记仍可从主导航查看。手机保持页眉/页脚固定，并在底部导航上方预留纸页空间。
- 原有湖边沉浸模式继续使用全屏画面，不套入手账框架。
- 页码为桌宠默认位置预留右侧空间；用户自定义拖动桌宠仍由用户控制。

## 回环验证

修改前 `notebook-layout.mjs` 失败于缺少独立内容容器。根因是页眉、主内容和页脚都放在同一个可滚动 main 内，且欢迎卡和聊天高度相加超过视口。

修改后 Vite/Docker 构建通过，8080 与隔离 18080 前端均更新。

- `notebook-layout.mjs`：1363×871、1363×650、781×871、390×871 四种窗口，四个页面共 16 组截图；滚轮前后页眉/页脚/外层位置一致，长设置页仍可阅读到底，陪伴页不整体滚动，输入区完整、消息区留有可用空间。湖边往返通过。
- `companion-scroll.mjs`：左右栏实际滚轮及底部不传递通过。
- `activity-chat.mjs`：讨论入口、草稿、上下文、失败重试通过。
- `diary-reader.mjs`：独立阅读/编辑/补充/返回日期通过。
- `full-regression.mjs`：完整五组浏览器回归全部通过。
- `diary-default.mjs`：默认数据快照一致，13 日记、2 画像未改变。
