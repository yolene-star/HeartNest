# 跨页宠物位置与拖动修复

2026-11-03。根因：坐标样式仅在「陪伴」页使用；pointerdown 明确排除非首页，且排除了宠物头像按钮。窄屏默认锚点和气泡宽度也仅针对首页，导致切页位置或尺寸变化。

现在所有显示悬浮宠物的页面统一使用同一个位置状态及本地持久化坐标，初次可见时也固定当前默认位置。头像与气泡可直接拖动，操作按钮继续作为按钮。头像轻点仍返回陪伴页，拖动结束的点击不会触发导航。捕获原始头像按钮的指针事件，避免轻点被外层容器截断；取消/丢失捕获时清理拖动状态。位置随窗口或宠物占位尺寸变化限制在视口内，手机隐藏宠物时不重写已保存位置。此前手机隐藏悬浮宠物及湖边单宠物规则保留。

验证：修改前 `pet-position.mjs` 失败于日记页头像不可拖。修改后发现并修正头像轻点被捕获的问题。
