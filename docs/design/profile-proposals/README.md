# 对话中的个人资料更新验收

## 行为

- 对话建议修改称呼、回应方式或记录习惯/个人特征；确认前只存在临时候选。
- 确认后刷新「我的」及欢迎称呼，候选可取消、保存失败可重试。
- 不保存聊天也可单独确认一项资料；确认卡片明确说明保存范围，不新增日记。
- 小习惯/个人特征单独列出，支持来源查看、手动补充、修改、删除。
- 对已有兴趣和灵活画像做本地去重，旧设置提议不覆盖新修改。

## 可复跑验证

后端：`python -m pytest -q`（Docker 内运行）。

最终结果：91 passed，1条既有依赖弃用警告；前端构建成功，前后端已部署默认与隔离 Docker 实例。最终后端调整后重新执行个人资料浏览器回环通过。

浏览器：在 frontend 执行 `node tests/profile-proposals.mjs`，使用独立的 localhost:18080 验收实例，LLM_ENABLED=false。测试完成恢复设置并删除自己生成的画像，不操作默认用户数据库。

新浏览器回环覆盖：确认前不保存、首次失败后重试、更新称呼与「我的」同步、取消、在不保存聊天时单独确认习惯、不生成日记、重复候选抑制、灵活画像不重复显示在兴趣区、编辑/删除、手机无横向溢出。截图为 desktop-confirm.png、desktop-profile.png、mobile-profile.png；结果为 results.json。已打开截图检查。

既有五组顺序浏览器回归均通过：日记选择、主要产品流程、补全流程、心情时间线、聊天记忆。

真实模型测试：自动审批拒绝了经本地后端向外部模型发送涉及回应偏好和社交特征的测试文字，因此没有发送。自然表达提取使用受控模型返回测试及本地规则验收，真实 DeepSeek 语义效果仍需用户允许后再验证。

## 边界

候选30分钟失效、服务重启失效；没有跨设备待确认队列。相似度去重不能保证语义全覆盖。没有模型时不能识别所有自然说法。已确认的小事可查阅修改，本轮不将其全部自动注入外部模型上下文。没有提交、推送或创建PR。
