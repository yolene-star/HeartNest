# 连续会话与交互留底验收

## 原因与修复

原来通过条件渲染挂载陪伴页，离开即卸载并清空其局部聊天状态。修复后在当前页面生命周期内保留同一个陪伴页实例，非活动时隐藏并关闭临时抽屉、弹窗及湖边场景；返回后继续同一会话。

最新规则：普通操作不追加聊天提示；仅活动咨询、请求小建议/练习及更换建议追加对应用户请求与 Agent 回应。请求失败保留一条用户消息，重试不重复。更换建议追加新回应和卡片，原卡片继续保留。

## 可复跑验证

在 frontend 执行：

```
node tests/conversation-continuity.mjs
node tests/profile-proposals.mjs
node tests/full-regression.mjs
node tests/conversation-reliability.mjs
```

所有可写场景均使用独立 localhost:18080 实例并关闭外部模型；设置在测试后恢复。

初始复现：新测试在离开日记页再返回时失败，原用户消息数量从1变为0。

新增场景：

- 日记、回顾、我的往返后保留原话、回应及未发送草稿。
- 日记快捷入口、放松选择/继续聊天/取消、湖边进入/聊天/返回和窄屏工具抽屉不清空会话且不追加操作提示。
- 活动入口保留真实发送内容，建议请求保留实际用户消息。
- 更换建议保留旧标题、步骤；拒绝反馈与卡片状态跨页保留。
- 等待回应期间切换页面，完成后返回仍见原会话回应。
- 资料确认失败/重试/确认/取消仅在原卡显示结果，不追加操作提示；确认状态跨页保持。
- 入口生成的建议请求不自动产生额外日记。

截图 desktop-history.png、narrow-history.png，运行结果 results.json。截图已打开检查。前端本地构建和 Docker 构建通过，更新已部署至默认8080及隔离18080实例。

最终结果：新增连续会话5组场景、资料更新回环、既有5组完整浏览器回归、5种会话故障重试场景全部通过，无页面脚本错误。既有建议来源断言已明确定位最新建议来源区域，允许同时保留旧建议卡片。

## 保留边界

本轮实现当前页面生命周期内的连续会话，不新增 localStorage/sessionStorage 聊天副本；刷新网页或关闭网页仍会结束临时会话。日记和长期记忆继续由用户单独决定是否保存。本轮未更改后端或外部模型配置，未提交推送代码。
