# 独立日记阅读页

2026-11-03：从心情日历点击「打开这篇日记」，进入独立阅读页，不混入记录列表或新建表单。返回恢复原月份和选中日期。

沿用鼠尾草绿与奶油色，使用简洁双线和四角信纸装饰。阅读头部显示日期及用户确认的情绪；未确认或跳过时不伪装成已确认心情。正文保留原文与换行，不生成虚构标题。原有编辑、补充、删除及记忆权限功能保留。

阅读页采用右侧纸页滚动，清除旧详情面板的 sticky top 偏移；手机进入时回到页首。外侧封面和书钉仍固定。
