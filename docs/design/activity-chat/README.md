# 在对话里一起想活动

2026-11-03：取消右侧活动筛选表单与活动列表，将「一起找个小活动」移到聊天输入区。点击直接发送一条正常用户消息，不强制触发练习建议卡：

> 我想找个适合现在的小活动，你能陪我一起想想吗？我们可以先聊聊想做什么，再慢慢考虑时间和预算。

用户继续在聊天中补充诉求、时间、预算和喜好。使用现有 LLM、会话上下文、记忆开关与单条保存选择；入口本身不额外开启保存，也不创建偏好。输入框已有草稿时保留。后台活动目录/反馈接口保留，独立筛选表单不再作为本版产品入口。未来若在聊天中执行结构化活动筛选，需明确接入工具；本轮不把普通聊天声称为已调用活动库。

回复后的自动滚动仅作用于消息容器，避免带动外层纸页。右侧仍保留日记与近期记录。
