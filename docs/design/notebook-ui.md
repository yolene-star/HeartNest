# 心栖：绿色活页手账界面

日期：2026-11-02。按用户提供的框架参考图落实第一版，视觉效果待用户认可；本地 Docker 已部署，尚未提交或合并代码。

## 设计落点

- 保留鼠尾草绿、嫩绿操作色、奶白与深绿色文字；参考图的蓝色不引入产品。
- 桌面以一本摊开的活页本为整体容器：左侧绿色格纹封内、品牌铭牌和编号目录，右侧奶白点阵纸页；五个装订环衔接左右，外缘叠纸形成笔记本轮廓。
- 四个主页面继续是陪伴、日记、回顾、我的。首页使用浅绿色纯色扉页和现有伙伴（按用户后续反馈移除欢迎区格纹，格纹仅保留在左侧封内），内容卡片改成纸片边框，日记入口加少量胶带；标题使用本机宋体类衬线字，正文保持易读的无衬线字体，不加载在线字体。
- 日历、日记编辑、七天回顾与设置沿用纸页体系；日记原文和输入区使用轻横线。页尾标记所属章节编号，不产生新的功能入口。
- 手机呈现单页便笺，保留底部四项导航；隐藏封内与装订环以节约宽度。平板保留目录，内容改为单列，活动入口独占一行，避免卡片被拉高。
- 情绪初判仍为默认折叠的轻提示。湖边保留独立沉浸风景，隐藏手账装饰，不改变聊天/记忆授权或角色素材。

装订环、胶带、格纹为 CSS 与无障碍隐藏的纯装饰，不拦截指针事件；导航仍为真实按钮，焦点样式和原可访问名称保留。

用户后续反馈多只宠物同时动画过于嘈杂：主页面只让悬浮桌宠使用动态 GIF；欢迎区、消息头像、手机导航、设置和伙伴选择使用原角色 `idle-0.png` 静态帧，聊天空白区移除重复宠物。静态形象不随聊天状态切换。湖边沿用独立的一只场景伙伴及减少动态选项，进入时悬浮桌宠隐藏。

该调整已重建并部署 Docker。`frontend/tests/pet-motion-budget.mjs` 验证五个角色的静态图成功加载、跨时间解码像素和位置不变；确认主页面仅悬浮 GIF 可见、思考时静态区不变、拖动与更换入口可用、湖边往返无重复动态。390/781/1440 截图保存在 `docs/design/pet-motion-validation/`，781 与390已打开检查。四页三宽回归及五组安静空间回归通过，临时测试未写入日记。
