# 湖边发呆：安静陪伴第一版

用户已确认手绘自然风景方向，并提供去除角色和界面的纯背景图。此版本将这张图用于正式 React 产品，不更改现有宠物资产、LLM 配置或后端数据结构。

## 使用流程

首页点击“陪我待会儿”进入全屏湖边。当前选择的宠物坐在草坡，隐藏侧栏和浮动桌宠，避免重复出现角色。进入时默认静音，不计时、不要求记录或反馈。

- **想聊聊**：在风景上展开原有聊天面板，沿用同一份草稿、消息和记忆保存选择。收起聊天或返回首页不会重置这些状态。
- **环境声音**：用户点击后才播放轻柔的合成环境声，可调节音量；关闭、离开页面或切到后台时停止并释放音频资源。本版声音由 Web Audio 本地合成，非实地湖水录音，无麦克风或额外联网权限。
- **换个地方**：列出实际可用的“湖边发呆”。当前仅一个场景，森林、窗边尚未制作，不显示可进入的虚假场景。
- **减少动态**：将现有 GIF 切换为现有静态帧、隐藏涟漪。进入时尊重系统减少动态偏好。宠物轻触仅短暂回应，不发起聊天或保存记录。
- **返回陪伴 / Escape**：聊天展开时 Escape 先收起聊天，场景选择弹窗打开时先关闭弹窗，否则返回陪伴。支持键盘焦点和选择弹窗内循环。

桌面保留宠物与风景，右侧可展开聊天；窄屏聊天面板暂时遮住宠物，收起恢复。手机背景使用裁切保留右侧草坡，无须额外生成手机图片。手绘背景保持静态，只增加少量低幅度涟漪。

## 资源

- 用户提供背景：`frontend/public/scenes/lakeside-watercolor.png`，直接复制原图，无重新生成或图像编辑。
- 宠物：沿用 `/pets/{角色}/idle.gif` 和 `idle-0.png`，未修改角色图片、GIF 或帧坐标。
- 页面：`frontend/src/QuietScene.jsx`、`quiet-scene.css`，入口与原有对话保持在 `ProductApp.jsx`。

## 验证

旧 Docker 页面运行新增测试，因不存在“陪我待会儿”入口而失败。部署后 `node tests/quiet-scene.mjs` 通过 5 组场景：背景与单宠物、真实音频上下文开启/关闭、草稿与聊天连续性、临时聊天不保存、宠物交互与场景选择、390/785/1440 布局及截图、减少动态、离开停音、角色切换。

截图检查发现并修正了旧页面最大宽度导致的左右留白，以及展开聊天后宠物落在水面上的问题。`nature-product.mjs` 的按钮定位已适配新增入口；10组界面回归和5组聊天记忆回归通过。浏览器验收在独立容器、关闭 LLM 的实例执行，本轮没有重新评估付费模型质量。

默认产品验收使用 `quiet-default.mjs --snapshot` 保存更新前编号，部署后只读核对，并生成本地截图和 `default-smoke.json`。验证产物位于 `docs/design/quiet-scene-validation/`。

实体手机软键盘和真实扬声器听感仍需人工体验。本版仅交付湖边场景，其余风景后续设计；未自动 commit 或推送。

默认8080实例已完成只读验收：湖边进入、展开与返回聊天、四项导航通过，更新前后14篇日记和2条画像的编号完全一致。已查看默认入口的实际截图 `quiet-scene-validation/default-lake.png`。
