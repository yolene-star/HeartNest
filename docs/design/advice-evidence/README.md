# 有依据的放松建议：实施与验证

日期：2026-11-03。使用虚拟日记和隔离数据库；未使用个人日记、未调用付费云端模型。本记录不是专业人员临床审核，也不代表零缺陷保证。

## 本次实现

- 固定动作库与来源登记：WHO 四类自助方法、音乐方向，以及用户明确的绘画/阅读偏好。来源不明的候选跳过，候选用尽后停止提供新动作。
- 每项动作返回文献/偏好/两者的依据、改编和局限；偏好保留当前表达、本次对话或已确认画像来源。历史画像仅在记忆开启后使用。
- 活动接口也遵循来源或明确偏好条件，时间与费用继续硬筛选。店铺、电影等不冒充有科学证据的干预，活动本身仍是模拟数据。
- 拒绝、换一种和不适在当前会话排除；确认长期避开才写入可编辑/删除的画像。报告不适先停止，不自动劝坚持或强推另一项练习。
- 明确的自然语言行动请求进入受控库；日常聊天继续自然回应。规则覆盖有限，不把 prompt 等同完整语义审核。

## 自动化与浏览器证据

后端：**174 passed**，1 条第三方 Starlette/AnyIO 弃用警告。命令在 Docker 中运行，`LLM_ENABLED=false`、`PUBLIC_DEMO=false`、临时 SQLite，挂载后端源码只读。

核心用例位于 `backend/tests/test_advice_policy.py` 和 `backend/tests/test_scenario_matrix.py`。后者使用开心、平静、疲惫与满足混合、低落、焦虑、说不清、Emoji、HTML 原文、多行及长篇虚拟日记，逐一验证保存→用户确认情绪→闰日月历→编辑→补充→撤销检索→删除。另测试聊天不擅自保存或改称呼、日期边界、空白编辑及补充。

前端：Vite 构建通过；Docker 镜像构建并部署到 18081 公网演示隔离实例、18080 验收实例。`node tests/advice-evidence.mjs` 通过 5 组真实 Edge 浏览器场景，桌面 1363×871、手机 390×844，无页面脚本错误。

验收通过后已更新默认 `http://localhost:8080/` 的前后端 Docker，沿用原有环境配置与数据卷。默认页面只读检查通过：新构建加载、固定页脚可见、无页面脚本错误；未在个人数据实例发送测试聊天或修改设置/日记。

1. 绘画为个人偏好依据，无虚构文献；依据默认折叠；拒绝后当前会话不重复，不新增画像。
2. 音乐为文献与偏好双来源；展开验证 PubMed 链接；确认不适后在「我的」可见并能删除；页面切换保留原聊天卡片。
3. 饮酒诉求不转成饮酒建议；明确拒绝不新增行动；未授权保存时无日记写入。
4. 直接要求呼吸练习进入受控库；“听音乐后不舒服”先停止，不追加动作；手机能滚动查看来源，无横向溢出。

截图已打开检查：`desktop-preference.png`、`mobile-literature.png`、`mobile-source-link.png`。长卡片在消息区内部滚动，页眉、页脚与输入框保持固定。`result.json` 保存新增浏览器验收结果。

## 发现并修复

- 活动接口在关闭记忆时仍读取历史画像；现已统一授权条件。
- 否定、历史或第三方的活动关键词被当作正向诉求；补充了保守筛选和回归。
- 自然语言练习请求绕过来源库；扩充入口识别，使用伪造不合规模型返回值证明该路径不再调用模型。
- 普通“不舒服”表达未触发停止；扩充并覆盖建议/聊天两种入口。
- 日记编辑与补充接受纯空白；加入去空白校验，失败请求保持原文不变。

## 仍有的限制

未做本轮真实 DeepSeek 服务、专业临床评价、疗效研究或所有自然语言表达的穷举测试。普通自由聊天仍受模型与意图识别误差影响；需要在真实使用中继续验收。文献只支持相应方向，产品缩短、翻译或个性化改编不代表已验证同等效果。模拟活动不核实真实营业、天气、地理和可达性。

提交前独立审查发现跨轮风险遗漏：前一轮报告听音乐失控影响学习，下一轮泛请求仍可能推荐音乐。新增用例先复现失败，再保留当前临时对话风险上下文；后端与浏览器回归通过。
