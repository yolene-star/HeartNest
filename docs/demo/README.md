# 备用演示录屏

打开 [heartnest-demo.webm](heartnest-demo.webm) 即可播放，约19.2秒、无声。可使用播放器的0.5倍速或暂停查看操作，适合作为现场演示失败时的备用材料。

内容来自实际网页操作：首次选择伙伴、聊天保存与情绪确认、建议来源、活动与偏好确认、画像、日历、日记补充、撤回单篇记忆许可和七天回顾。全部使用虚构演示内容，录制环境使用离线规则；不代表真实大模型的响应效果。

`recording.json` 记录操作结果；`video-review.json` 记录解码检查，三个 `review-*.png` 是已查看的抽帧。真实 DeepSeek 验证另见 `../completion-validation/llm/`。
