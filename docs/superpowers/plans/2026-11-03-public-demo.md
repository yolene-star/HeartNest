# HeartNest 公网演示实施计划

**目标：** 在独立 Docker 环境中提供可验证的公网 HTTPS 演示，并追加到 PR #29。

**架构：** 保持现有单用户本地模式。公网模式在现有请求锁内切换独立访客 SQLite 快照，使用随机 HttpOnly Cookie，闲置 24 小时后清理。演示不读取本地 API 配置。Cloudflare 临时隧道连接独立的 18081 端口。

- [x] 后端：先验证访客隔离测试失败，再实现会话、过期清理和私有默认数据隔离。
- [x] 部署：独立 compose、公网启动/停止脚本，默认禁用收费模型。
- [x] 前端：低干扰的演示说明，不改变固定页眉和滚动布局。
- [x] 验证：完整后端测试、前端构建、Docker、两个浏览器上下文、桌面/窄屏截图及真实 HTTPS 检查。
- [x] 交付准备：运行说明、限制和验证记录齐全，按功能普通提交；统一推送并更新现有 PR，不重写历史。
