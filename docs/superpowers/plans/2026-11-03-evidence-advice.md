# 有依据的放松建议实施计划

目标：每条建议来自受控文献方法或明确偏好，经适用性筛选；保持聊天自然、拒绝不自动变成长期画像。

- [x] 编写后端失败用例：来源、授权、否定/转述/历史、风险、拒绝和资料删除。
- [x] 实现独立建议策略模块和来源登记，绑定既有聊天与反馈接口。
- [x] 前端折叠依据，新增不适反馈及确认长期避开，当前会话排除拒绝项。
- [x] 隔离环境中运行多种长短日记、操作和聊天场景，排查并修复失败。
- [x] 构建、Docker 部署、真实页面操作、截图检查和记录实际限制。

159 项后端测试及新增/既有浏览器回归通过；经过独立代码审查并修复自然练习请求及不适表达漏判。证据与边界见 `docs/design/advice-evidence/README.md`。测试不等于零缺陷或专业疗效审核，普通聊天的任意模型输出尚无完整语义审核。

不将模型提示词当作已完成约束。先保持动作和证据为后端受控文本，自然语言聊天继续使用既有 LLM；不允许模型扩写未经校验的行动或文献。偏好识别首版采用保守规则，未覆盖的表达先澄清，不能承诺通用语义理解。
