# 数据说明

- `diaries.json`：脱敏演示日记与聊天记录。
- `profiles.json`：由用户明确表达并确认的兴趣画像样例。
- `activities.json`：课程原型模拟活动，包含名称、类别、时间、费用、描述和来源。
- `classification_metrics.json`：人工编写模拟文本的分类实验结果，不代表真实用户表现。
- 真实个人日记不作为提交包必要数据。

公开八类实验、授权声明与产品标签关系见 [来源说明](../docs/data/sources-and-labels.md)；完整输入、保存、派生字段见 [字段字典](../docs/data/dictionary.md)。这些样例文件不是个人运行数据库，也不自动代表已确认的真实用户事实。
